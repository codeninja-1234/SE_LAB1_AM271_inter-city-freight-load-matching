## Run on macOS
From this directory, run:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install pylint bandit flake8
bash generate_reports.sh
python expense_tracker.py
```

The report script runs each tool against the baseline source and the final source. Tool output is saved even when a tool exits with a non-zero status because findings were detected. After fixes, Pylint should score above 9.5, Bandit should report no issues, and Flake8 should produce an empty report.

## Security choices
- The sync password is read from `BANK_SYNC_PASSWORD`, not stored in source code.
- Password comparison uses `hmac.compare_digest`.
- Reports use `NamedTemporaryFile` instead of `tempfile.mktemp`.
- Shell-based file opening was removed.
- Negative budgets are rejected and the empty-expense case is handled explicitly.
